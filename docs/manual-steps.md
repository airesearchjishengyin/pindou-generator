# 图豆收费化 — 你需要亲自操作的部分（操作手册）

> 更新: 2026-09-25。**完整流程手册已迁移至 `docs/sole-proprietor-filing.md`（个体户→备案→商户号→小程序五阶段）**, 本文档保留作快速参考。

## 第 0 步 · 现在就能做的（0 成本，今天可上线收款）

技术侧已就绪：
- 公网地址: **https://tudou.macagents.org**（已实测 health/页面正常）
- 收费方式: 用户在网页扫码付款 → 你发兑换码 → 用户输码解锁 AI 像素化
- 发码命令（文档见 `docs/payment-mvp.md`）:
  ```bash
  curl -X POST https://tudou.macagents.org/api/license/gen \
    -F admin_key=<你 .env 里的 PINDOU_ADMIN_KEY> -F count=1 -F max_uses=1
  ```

你只差两样东西：
1. **个人收款码图片**，导出后放到 `~/pindou-generator/static/pay-qr.png`
   （微信：我→服务→收付款→二维码收款→保存收款码；支付宝同理。建议备注里写"图豆 AI"）
2. **定价**：AI 接口成本约 0.2–0.4 元/张，建议 ¥3–5/次。改价格在 `static/index.html` 搜 `pwPrice`

> ⚠️ 个人收款码收经营款属于灰色地带（平台条款不允许用于经营），单量小没人管，
> 但这就是为什么要尽快办个体户——办下来就能转正。

## 第 1 步 · 注册个体工商户（约 1–3 天，全程免费）

**费用：0 元。** 工商登记不收任何工本费；税务登记免费；刻章可免（个体户不强制刻章）。

办理方式（选一）：
- **线上**：你所在省的政务服务网 / 当地"市监"小程序，搜"个体工商户设立登记"，
  人脸识别实名后在线填表，全程网办，电子执照直接下发
- **线下**：经营场所所在区市场监管局窗口，带身份证即可

需要准备：
| 材料 | 说明 |
|---|---|
| 身份证 | 经营者本人 |
| 经营场所证明 | 可用自有住宅（多数城市允许"住改商"承诺制，无需居委会盖章）；租房则要租赁合同 |
| 名称 | 格式如 `XX市XX区+字号+行业+工作室/经营部`，建议含"设计"或"科技" |
| 经营范围 | 建议勾选：**平面设计、工艺美术品制作销售、软件开发、互联网信息服务**（覆盖拼豆图纸设计与线上销售） |

注册后 30 天内去电子税务局做**税务登记**（免费，选小规模纳税人，月销售额 10 万以下免增值税）。

## 第 2 步 · 域名备案（个体户执照下来后，约 1–2 周）

- 域名建议直接用 **tudou.macagents.org 的主域 macagents.org**（已在 Cloudflare，
  但注意：CF 托管 + 国内备案需要把解析切回国内服务商或使用 CF 中国版；也可以另购一个 ~¥50/年的 .com/.cn 专门做这个项目）
- 备案主体：个体工商户（企业性质备案），通过你买云服务器的厂商提交
  （腾讯云/阿里云都有免费备案辅助服务，需先买一台最便宜的国内服务器 ~¥100/年作为备案跳板）
- 网站内容写"拼豆图纸设计工具"，不写"经营性"字样也能过，但要如实勾选"有偿服务"

## 第 3 步 · 微信支付商户号（备案下来后，约 3–7 天）

1. pay.weixin.qq.com → 接入微信支付 → 主体类型选**个体工商户**
2. 材料：执照、经营者身份证、绑定银行卡（个体户可用**经营者个人储蓄卡**，无需对公账户）
3. 经营场景选 **JSAPI（小程序支付）** 或 Native（PC 扫码）
4. 结算周期 T+1，手续费 0.6%（部分行业 0.38%）

## 第 4 步 · 升级收费方式（可选两条路）

**路线 A · 继续 Web 版**：备案网站 + 微信 Native 支付（扫码跳微信付款），
把现在的兑换码面板换成"微信扫码支付 → 自动解锁"，兑换码逻辑保留当备用。

**路线 B · 小程序**（推荐，转化率高）：
1. mp.weixin.qq.com 注册小程序，主体=个体工商户，类目选 **工具 > 效率** 或 **生活服务**
2. 后端直接复用图豆 server.py（加个小程序登录接口即可）
3. `wx.requestPayment` 对接商户号，AI 像素化按次付费
4. ⚠️ 小程序审核对 AIGC 类目可能要求提供**已备案大模型证明**——到时把图生图 API 切到
   已备案的国产模型（通义万相 wanx / 混元生图 / 豆包生图，接口形态类似，切换成本低），
   `pindou.py` 的 `ai_pixelate()` 只需改 base_url 和 model 两个参数

## AIGC 合规（已做 + 待做）

- ✅ 已做：所有 AI 生成的图纸/预览自动带「AI 生成」标识（《人工智能生成合成内容标识办法》2025-09-01 生效）
- ⬜ 待你决定上线平台后：若上小程序，图生图模型需切换已备案国产模型（第 4 步路线 B 第 4 点）
