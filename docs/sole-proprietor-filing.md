# 国内个体户备案 → 收款上线 · 完整操作手册

> 更新: 2026-09-25。目标: 个体工商户执照 → 网站备案 → 微信支付商户号 → 小程序(可选) →
> 收款全自动。全程政府端 **0 工本费**, 总耗时约 **4–8 周** (大头是备案等待)。
> 本手册按"每一步做什么、在哪做、要什么材料、等多久"写, 照着做即可。

---

## 总览: 五个阶段

| 阶段 | 内容 | 耗时 | 花费 |
|---|---|---|---|
| ① 个体户注册 | 执照到手 | 1–3 个工作日 | 0 元 |
| ② 税务登记 | 30 天内完成 | 半天(线上) | 0 元 |
| ③ 域名+ICP备案 | 网站合法化 | 1–3 周 | 服务器 ~¥100/年 (备案用最便宜的) |
| ④ 微信支付商户号 | 能收钱了 | 3–7 天 | 0 (费率 0.6%/笔) |
| ⑤ 小程序 (可选) | 体验最好 | 1–2 周 | 认证 ¥30/年 |

阶段①②期间现有收费方式(兑换码+人工入账)照常跑, 不冲突。

## 阶段① · 个体工商户注册 (1–3 天)

### 1.1 办理渠道 (二选一, 推荐线上)

- **线上**: 你所在省的政务服务网 (如浙江"浙里办"、广东"粤商通"、上海"一网通办"),
  搜 **"个体工商户设立登记"**; 部分省份走"市场监管"小程序。人脸识别实名 → 在线填表 →
  电子签章 → 审核通过后发 **电子营业执照** (和纸质同等效力, 在"电子营业执照"微信小程序里领取)
- **线下**: 经营场所所在区的**市场监管局注册大厅**窗口, 带身份证原件, 现场填表,
  通常当场或次日拿照

### 1.2 需要准备的材料

| 材料 | 说明 |
|---|---|
| 身份证 | 经营者本人, 原件 |
| 经营场所证明 | **自有住宅**: 多数城市支持"住改商"承诺制 (填一张承诺书即可, 不用居委会盖章); **租房**: 租赁合同 + 房东房产证复印件。没合适地址可咨询当地是否提供免费的"集群注册"地址 |
| 拟用名称 2–3 个 | 格式: `所在区 + 字号 + 行业 + 组织形式`, 例: `XX市XX区XX豆设计工作室`。注意: 组织形式只能用 **工作室/经营部/服务部/中心**, 不能带"公司"; 字号避免与当地同行业重名 |
| 经营范围 | 直接照抄这段: **平面设计; 工艺美术品及礼仪用品制造、销售; 互联网销售; 软件开发; 信息技术咨询服务; 广告设计、代理** (覆盖拼豆图纸设计+线上卖图纸+软件服务, 涵盖AI生图服务) |

### 1.3 填表要点

- 组成形式选 **个人经营** (不选家庭经营, 简单)
- 从业人数: 1
- 领照方式: 选 **电子执照** (纸质可后补)

### 1.4 拿到执照后立即做

1. 下载 **电子营业执照** 微信小程序, 用你身份证绑定的微信"下载执照"
2. 复印/截图留存: 执照上有个体户名称、统一社会信用代码、经营者姓名、经营范围

## 阶段② · 税务登记 (执照后 30 天内, 半天)

1. 下载 **电子税务局** App (或省税务局网站), 实名登录
2. 办 **税务登记确认** (新办纳税人套餐), 系统通常已按执照自动生成, 核对即可
3. 三个必选项:
   - 纳税人类型: **小规模纳税人**
   - 征收方式: **查账征收** (个体户默认; 若只能核定征收也没问题, 更省事)
   - 申报周期: **按季** (一季度报一次, 省 3/4 的申报次数)
4. **免费额度** (2026 年现行政策): 月销售额 ≤10 万 (按季 30 万) 免增值税;
   经营所得个税个体户有减半征收优惠。以图豆现在的体量, **基本税负为 0**
5. 开不开对公账户: **个体户可以不开对公**, 用经营者个人银行卡收款 (微信支付商户号支持绑个人卡)

> ⚠️ 每季度即使 0 收入也要点一次"零申报", 不报会有罚款记录。电子税务局 App 里 1 分钟完成。

## 阶段③ · 域名 + ICP 备案 (1–3 周)

### 3.1 域名

- 建议新购一个便宜域名 (**.com/.cn**, ¥30–60/年, 阿里云/腾讯云都可), 专用于图豆
  (不建议复用 macagents.org——它在 Cloudflare 海外解析, 备案需转回国内服务商, 折腾)
- 域名实名认证: 用**个体户名义**认证 (备案要求域名所有者与备案主体一致或有关联)

### 3.2 备案流程 (以腾讯云/阿里云为例, 两家都免费代办)

1. 买一台最便宜的国内云服务器 (**轻量应用服务器 ~¥50–100/年** 即可, 只做备案跳板+未来挂图豆)
2. 服务器控制台 → **ICP 备案** → 开始备案
3. 填写: 主体=个体工商户 (传执照照片、经营者身份证), 网站信息:
   - 网站名称: 如 `XX豆拼豆图纸` (避免"商城/平台/在线交易"等敏感词)
   - 网站内容/服务类型: 选 **"其他"或"信息服务"**, 备注: "拼豆图纸设计工具, 提供在线图片转换设计服务"
   - 是否提供有偿服务: 如实选 **是** (有偿信息服务, 个体户性质允许)
4. 域名核验 + 人脸核身 (App 上 5 分钟)
5. 管局审核 (通信管理局): **省局审核 1–20 天**, 大多数省份 1–2 周
6. 通过后你会拿到 **ICP备案号** (如 粤ICP备2026XXXXXX号), 必须挂在网站页脚

### 3.3 备案期间服务器上可以先做的事

- 把图豆 server.py 部署上去 (备案号下来才对外开放 80/443)
- 挂一个"建设中"页, 页脚预留备案号位置

## 阶段④ · 微信支付商户号 (备案号到手后, 3–7 天)

### 4.1 申请

1. **pay.weixin.qq.com** → 接入微信支付 → 主体类型: **个体工商户**
2. 材料: 执照、经营者身份证、**经营者个人储蓄卡** (个体户无需对公账户)、
   备案号 (网页场景需要已备案域名)
3. 经营场景勾选:
   - **Native支付** (网页版: 用户微信扫码付款, PC 网站用) ← 图豆 Web 版用这个
   - **JSAPI支付** (小程序内支付, 阶段⑤用)
4. 结算账户: 绑个人卡; 结算周期 T+1; **费率 0.6%** (部分行业 0.38%)
5. 超级管理员 = 你自己的微信

### 4.2 拿到商户号后我这边接入 (Hermes 完成)

- server.py 加微信 Native 支付: 用户点"充值" → 系统生成订单+金额 →
  微信扫码 → 微信回调 server → **自动入账+自动加赠** → 彻底告别手动 curl
- 需要你提供: 商户号 mchid、商户 API 证书 (商户平台"API安全"里下载)、APIv3 密钥

### 4.3 充值档位建议 (对接自动入账时用)

| 档位 | 到账 | 折合单次 |
|---|---|---|
| ¥10 | ¥11 | 12 次 |
| ¥20 | ¥23 | 25 次 |
| ¥50 | ¥57 | 63 次 |

## 阶段⑤ · 微信小程序 (可选, 1–2 周)

> 价值: 用户体验最好 (微信内直接用), 但 **AI 类目有额外资质门槛**, 见 5.3。

### 5.1 注册

- mp.weixin.qq.com → 立即注册 → 小程序 → 主体: **个体工商户**
- 认证费 ¥30/年
- 类目: **工具 > 效率** (先用这个, 不带 AI 字样, 审核最松)

### 5.2 支付

- 小程序后台关联你的微信支付商户号 → 前端 `wx.requestPayment` → 完成

### 5.3 ⚠️ AI 功能的类目门槛 (重要)

小程序若提供 AI 生图功能, 微信审核会要求补充 **"深度合成-AI绘画"类目**, 资质二选一:

1. 自己申请《互联网信息服务算法备案》(个人/个体户基本下不来, 不考虑)
2. **借用大模型厂商资质** (推荐): 用已备案的国产大模型 API (通义万相/混元/文心等),
   厂商会提供:
   - 该算法的《互联网信息服务算法备案》截图 (备案编号可查)
   - 与你主体的《大模型服务合作协议》(阿里云百炼/腾讯云等签了协议就给)
   两份材料 + 你的小程序主体即可过"深度合成-AI绘画"类目审核

**对策**: 图豆 `ai_pixelate()` 已预留模型切换 (`OPENAI_BASE_URL`/model 参数),
到时把图生图换成阿里云百炼的通义万相 (国内直连、已备案、协议现成), 并在阿里云签合作协议拿材料。
技术改造半天, 资料申请约 1 周。

### 5.4 上架前合规清单

- [ ] AI 生成图带标识 (图豆已内置 ✓)
- [ ] 用户协议 + 隐私政策页 (说明图片仅用于生成、不上传第三方; 用了哪家大模型要写明)
- [ ] 页脚挂 ICP 备案号
- [ ] 收费方式与价格公示

## 时间线 (并行推进)

```
第 1 周    ①提交个体户申请 ──────────────── 执照(1-3天)
           ②税务登记(执照后立即)
           ③买域名+服务器, 提交ICP备案
第 2-4 周  ③等管局审核 ←────────────────── 等待期继续兑换码人工收款
第 4-5 周  ④拿备案号 → 申请微信支付商户号(3-7天) → Hermes 接自动回调
第 5-6 周  ⑤(可选)注册小程序 → 签大模型协议 → 提交类目审核 → 上线
```

## 卡点与对策

| 卡点 | 对策 |
|---|---|
| 住改商被要求居委会盖章 | 换"集群注册"地址(问当地市监局)或直接线下窗口问承诺制 |
| 备案被驳回(名称/内容敏感) | 网站名避开"支付/商城/平台"; 备注如实写"设计工具" |
| 小程序深度合成类目被拒 | 先上不带 AI 的纯转换版(算法转换不需要该类目), AI 版拿齐协议资质再提审 |
| 个人收款码继续收经营款 | 办下商户号前控制量级; 商户号下来立即切换 |
